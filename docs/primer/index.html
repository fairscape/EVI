EVI

Evidence Graph Ontology

Example Turtle Specification OWL GitHub

EVI records how a scientific result was produced — who ran which computation, on which dataset, with which software — and treats that provenance as evidence. It extends W3C PROV-O and Schema.org. Support and challenge relations can connect those records so a defect in data, software, or method can be traced to the findings that depend on them.

A worked example

  1. Mary created a dataset.
  2. The dataset has a schema (age, sex, birth weight).
  3. Her computation used that dataset and SciPy.
  4. It generated a result dataset, which also has a schema.
